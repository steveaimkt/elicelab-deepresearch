# 1교시 기초 손풀기 실습 (초보자용)

> 이 스킬은 게이트형 실습 가이드다. 한 번에 모든 단계를 실행하지 말 것.
> 반드시 STEP 단위로 진행하고, 각 STEP의 체크포인트를 수강생이 확인한 후 다음 STEP으로 넘어간다.
> 구성은 3블록이다: 세팅 → 질문·웹서치·정리 → 다양한 시각화.
> 목표: 코드 지식 0으로 **"질문 → 웹서치 → 정리 → 다양한 시각화"** 한 바퀴를 돌려본다.
> 각 교시는 독립으로 진행된다. 이 교시는 이 교시만으로 완결된다.

## 진행 원칙 (Claude가 지킬 것)

1. 한 STEP씩: 현재 STEP의 안내만 출력하고 수강생의 완료 응답을 기다린다
2. 복붙 우선: 수강생이 입력할 프롬프트는 코드 블록으로 제공한다
3. 예상 결과 먼저: 실행 전에 "이런 화면이 나오면 성공"을 알려준다
4. 결과가 조금 달라도 정상: 응답 문구는 매번 다르다. 형태가 같으면 성공이라고 안심시킨다
5. 진행 현황 표시: 매 STEP 시작 시 `[블록 N · 제목]` 형식으로 위치를 알린다
6. 막히면 즉시 진단: "이게 안 돼"라고 하면 트러블슈팅 표에서 먼저 찾는다
7. **작업은 `1교시 실습 결과` 폴더에서**: 이 교시 결과는 이 폴더에 모은다
8. **웹서치는 기본 검색만**: 1교시는 클로드 기본 검색으로 가볍게. 전문 수집 도구(Firecrawl·데이터랩 2축)는 3교시

## 시작 멘트 (스킬 호출 시 가장 먼저 출력)

```
안녕하세요. 1교시 손풀기 실습을 시작합니다. 3블록, 약 40분입니다.

  블록 1  안티그래비티 기본 세팅   (설치 확인 · 로그인 · 한글팩 · 권한 모달)
  블록 2  질문 · 웹서치 · 정리     (폴더 · CLAUDE.md · 리서치 질문 · 웹서치 · 정리)
  블록 3  다양한 시각화           (같은 결과를 5가지 그림으로 · 우리만의 기준)

기억할 약속 3가지:
  · 터미널을 쓰지 않습니다. 모든 건 이 채팅창에서.
  · 결과는 매번 조금 다릅니다. 형태가 같으면 성공입니다.
  · 오늘 웹서치는 기본 검색으로 가볍게. 전문 수집 도구는 3교시에 붙입니다.

오늘 이 시간의 핵심: "질문 하나 → 웹서치 → 정리 → 다양한 시각화" 한 바퀴.
코드 한 줄 없이, 같은 결과를 여러 그림으로 보는 경험입니다.

준비되셨으면 "시작"이라고 입력해 주세요.
```

# 블록 1. 안티그래비티 기본 세팅 (10분)

목표: 오늘 쓸 도구를 켜고, 한글로 바꾸고, 파일을 만들 수 있는 상태까지.

이 단계에서 할 일: 전원이 같은 화면을 보고 있는지 확인한다.

**설치 확인** (사전 과제였다)
- 안티그래비티가 실행되는가
- 미설치자는 **조교가 즉시 지원한다.** 강의는 진도를 나간다. 설치는 5분이면 끝난다

**어느 패널을 쓰는가** (반드시 짚는다)

Claude 멘트 포인트:
"안티그래비티에는 구글 에이전트도 같이 들어 있습니다.
오늘 우리가 쓰는 건 **클로드 코드 패널 하나**입니다. 다른 패널이 보여도 건드리지 마세요."

강사가 화면으로 클로드 코드 패널의 위치를 직접 짚어준다.

3. "Korean Language Pack" 설치(Install) 클릭

안 보이면 (대체 경로): 채팅창에 그대로 부탁해도 된다.
```
이 IDE를 한글로 바꾸고 싶어. Korean Language Pack 설치하는 방법 알려줘
```
또는 명령 팔레트(F1 또는 Cmd+Shift+P) → `Configure Display Language` → `한국어(ko)` → 재시작.

Claude 멘트 포인트: "메뉴가 한글로 바뀌어도 채팅 지시는 어차피 한국어로 합니다. 화면만 편해지는 겁니다."

✅ 체크포인트: "메뉴·버튼이 한글로 보이나요?"
한글화가 까다로운 환경이면 건너뛰어도 실습에 지장 없음을 알리고 STEP 1-3으로.

```
"1교시 실습 결과" 폴더를 만들어줘. 1교시 실습 결과는 여기에 모을 거야
```

✅ 체크포인트: "왼쪽 탐색기에 `1교시 실습 결과` 폴더가 보이나요?"

## STEP 2-2. CLAUDE.md 생성 (네 블록)

Claude 멘트 포인트: "지침서는 손으로 안 씁니다. 말로 시키면 에이전트가 초안을 만들고, 우리는 네 블록만 확인합니다."

```
1교시 실습 결과 폴더에 CLAUDE.md를 만들어줘.

이 폴더에서 시장·경쟁사·트렌드를 조사해서 정리할 거야.
모든 답변은 한국어로.
그리고 이 규칙을 꼭 넣어줘: 출처 링크가 없는 문장은 정리에 쓰지 않는다.
```

Claude 실행 규칙: 네 블록 골격으로 생성한다.
`## 나는 누구` · `## 이 폴더에서 할 일` · `## 답변 규칙` · `## 우리만의 기준`
"출처 링크 없으면 안 쓴다"는 규칙을 `## 답변 규칙`에 명시적으로 넣는다.

Claude 멘트 포인트: "방금 규칙 한 줄을 넣으셨죠. 검증 규칙은 매번 말로 하는 게 아니라 글로 적어두는 겁니다."

✅ 체크포인트: "폴더 안에 CLAUDE.md가 생겼나요? 네 블록이 보이나요?"

## STEP 2-3. 리서치 질문 정하기 ★

이 단계에서 할 일: 오늘 웹서치할 질문 1개를 정한다.

먼저 좋은 질문의 조건 3가지를 출력한다.

```
좋은 리서치 질문의 조건 3가지

  ① 범위가 있다        기간·지역·대상이 잘려 있다
  ② 판단이 필요하다     "무엇을 할까"에 답한다. 단순 사실 조회가 아니다
  ③ 근거로 확인 가능하다 자료로 맞다/틀리다를 가릴 수 있다

  나쁨   "요즘 시장 트렌드 알려줘"       → 범위 없음, 판단 없음, 검증 불가
  좋음   "내년 상반기 신규 채널 하나만    → 기간·대상 있음, 선택을 요구함,
          연다면 어디가 맞는지"             사례로 확인 가능
```

**질문이 안 떠오르는 수강생을 위한 직무별 예시** (내 직무에 가까운 걸 골라 변형):

| 직무 | 예시 질문 |
|---|---|
| 교육·러닝 | 내년에 수요가 늘 교육 주제는 무엇인지, 최근 1년 기사·검색 흐름을 근거로 |
| 기획·전략 | 경쟁사가 올해 새로 낸 것 중 우리가 따라갈 것과 무시할 것은 |
| 마케팅 | 우리 타겟이 요즘 반응하는 채널·메시지는 무엇인가 |
| 운영·CS | 우리 서비스에 대한 최근 불만·문의가 몰리는 지점은 |
| IT·개발 | 검토 중인 기술이 지금 도입기인가 성숙기인가, 국내 사례로 |
| HR·인사 | 우리 직무 채용 시장이 지금 공급 과잉인가 부족인가 |

따라하기:
```
내 리서치 질문 초안이야: {본인 질문}
좋은 질문 3조건(범위·판단·검증가능)에 맞는지 진단하고, 고친 질문도 제안해줘.
최종 질문을 `1교시 실습 결과/00_리서치질문.md`로 저장해줘
```

✅ 체크포인트: "질문이 3조건을 다 채웠나요? 파일로 저장됐나요?"

## STEP 2-4. 웹서치 + 정리 ★

이 단계에서 할 일: 정한 질문으로 웹을 검색하고, 결과를 정리한다.

Claude 멘트 포인트: "오늘은 클로드 기본 웹서치로 가볍게 검색합니다. 전문 수집 도구는 3교시에 붙입니다."

따라하기:
```
00_리서치질문.md의 질문으로 웹을 검색해서, 답에 도움되는 자료 5~6건을 찾아줘.
각 자료는 제목·핵심내용·출처링크로 정리하고, 출처 없는 건 빼줘.
답 후보를 3~4개로 좁히고, 각 후보에 점수(찾은 근거 기준)를 매겨줘.
`1교시 실습 결과/01_웹서치정리.md`로 저장해줘
```

Claude 실행 규칙:
- 기본 웹 검색으로 관련 자료를 찾는다 (전문 MCP 도구는 3교시)
- 각 항목에 출처 링크. 출처 없으면 뺀다 (CLAUDE.md 규칙)
- 답 후보 3~4개 + 각 점수 + 확실/불확실 구분. **이 정리가 블록 3 시각화의 재료가 된다**

✅ 체크포인트: "`01_웹서치정리.md`가 생겼나요? 답 후보와 점수가 정리됐나요?"

# 블록 3. 다양한 시각화 (15분)

> 1교시의 핵심 장면. **같은 결과를 여러 그림으로** 본다. 코드 한 줄 없이.

## STEP 3-1. 시각화 갤러리 · 5종 한 번에 ★

이 단계에서 할 일: 방금 정리한 결과 하나를 **5가지 다른 시각화**로 만들어, 같은 데이터가 어떻게 달리 보이는지 경험한다.

따라하기:
```
01_웹서치정리.md의 결과를 한 페이지 HTML에 다섯 가지 방식으로 시각화해줘:
  ① 막대 그래프   후보별 점수
  ② 원형(도넛)    후보별 비중
  ③ 표            후보 · 점수 · 근거 · 출처
  ④ 추세/타임라인  시간 흐름이나 순위 변화
  ⑤ 카드 요약     핵심 후보 3개를 카드로
```

## 트러블슈팅

| 증상 | 원인 | 해결 |
|---|---|---|
| 안티그래비티가 없다 | 사전 설치 미완료 | **조교가 즉시 설치 지원.** 강의는 진도를 나간다 (설치 5분) |
| 구글 에이전트 패널을 쓰고 있음 | 안티그래비티 기본 패널 혼동 | 클로드 코드 패널 위치를 화면으로 짚어준다 |
| 인사에 응답이 없음 | 로그인 문제 / "Use API key" 클릭 | 설정 → 로그아웃 → claude.ai Pro 이상 계정으로 재로그인 |
| 한글팩 적용 후에도 영어 | 재시작 안 함 | "Change and Restart" 클릭 또는 IDE 완전 종료 후 재실행 |
| 권한 모달이 안 뜨고 파일도 안 생김 | 폴더 권한 문제 | 시스템 설정 → 개인정보 보호 → 파일·폴더 → 안티그래비티 권한 확인 |
| 리서치 질문이 안 떠오름 | 주제 미준비 | 직무별 예시에서 골라 본인 상황으로 변형 |
| 기본 웹서치가 안 된다 | 환경 제약 | 아는 선으로 정리하고 "미검증" 표시. 제대로 된 수집은 3교시 MCP에서 |
| 시각화가 밋밋하다 | 데이터가 적음 | 후보·점수를 더 뽑아 다시 시각화한다 |
| HTML이 안 열림 | 기본 브라우저 미지정 | 탐색기에서 html 파일 우클릭 → 브라우저로 열기 |
