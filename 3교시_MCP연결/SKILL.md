# 3교시 MCP 연결 + 도구별 조사 (게이트형·독립)

> 이 스킬은 게이트형이다. 한 번에 다 실행하지 말 것.
> 게이트 하나 = 응답 하나 + 질문 하나. 수강생 답을 받고 다음 게이트로 넘어간다.
> 목표: 클로드에 손 두 개를 붙이고, 각 도구로 직접 한 건씩 조사해 결과 md와 시각화를 만든다.
> 이 교시는 스킬(SKILL.md)을 만들지 않는다. 손으로 직접 조사한다. 스킬로 굳히는 건 4교시.

## 진행 원칙 (Claude가 지킬 것)

1. 한 게이트씩: 현재 게이트만 안내하고 수강생의 완료 응답을 기다린다
2. 예상 결과 먼저: "이런 게 나오면 성공"을 실행 전에 알린다
3. 복붙 우선: 수강생이 입력할 프롬프트는 코드 블록으로
4. 진행 현황 표시: 매 게이트 시작 시 `[G번호 · 제목]`
5. **주제는 직무에 맞게**: G1에서 직무 팔레트로 각자 자기 주제를 고르게 한다
6. **각 도구로 한 건씩**: 같은 키워드를 Firecrawl(원문)·데이터랩(수요)로 각각 조사한다
7. 막힌 사람은 조교에게: MCP 연결 실패자를 기다리느라 전체 진도를 멈추지 않는다

## 시작 멘트

```
3교시를 시작합니다. 클로드에 손을 붙입니다.

지금까지 클로드는 "아는 것"만 답했습니다. 눈은 있는데 손이 없었죠.
이제 손 두 개를 붙입니다. 각각 다른 질문에 답합니다.

    Firecrawl        "원문은 뭐라고 하나"    관련 기사·페이지를 넓게 찾고, 본문을 통째로
    네이버 데이터랩    "얼마나 찾나"          검색 트렌드 (실제 수요)

  ★ 오늘은 각 도구로 한 건씩 직접 조사합니다.
    그리고 둘을 겹쳐 봅니다. 기사·원문은 "뜬다"는데 검색량은 제자리다?
    업계만 밀 뿐, 소비자는 아직 모릅니다. 그 엇갈림에서 인사이트가 나옵니다.

  ⚠️ 데이터랩은 "얼마나 검색되는가"를 줍니다. "광고가 얼마나 팔았는가"는 안 줍니다.

7단계로 갑니다 (약 55분):

  G0  MCP 발급 + 연결       (15분)  ← 회원가입·키 발급부터 대화창 연결까지
  G1  직무별 주제 고르기      (5분)
  G2  Firecrawl 원문 조사 ★  (10분)
  G3  데이터랩 수요 조사 ★    (10분)
  G4  결과 md + 2축 교차 ★   (10분)
  G5  시각화                (5분)
  (G6  환각 시연은 선택 · 시간 남으면)

준비되셨으면 "시작"이라고 입력해 주세요.
```

# G0. MCP 발급 + 연결 (완전 초보 기준) (15분)

목표: Firecrawl과 네이버 데이터랩의 키를 직접 발급받고, **대화창에 입력해서** 연결한다. JSON 파일은 건드리지 않는다.

Claude 멘트 포인트: "오늘은 설정 파일을 직접 고치지 않습니다. 키를 발급받아서 채팅창에 그대로 넣으면, 클로드가 알아서 연결합니다. 처음이어도 하나씩 따라오시면 됩니다."

## G0-1. Firecrawl 키 발급 (회원가입부터)

이 단계에서 할 일: Firecrawl에 가입하고 API 키를 받는다.

1. 브라우저에서 **https://www.firecrawl.dev** 접속
2. 오른쪽 위 **Sign Up**(회원가입) 클릭
3. **Continue with Google**(구글 계정)로 가입이 가장 빠르다
4. 로그인되면 왼쪽 메뉴에서 **API Keys** 클릭
5. `fc-`로 시작하는 키를 **복사**한다 (없으면 **Create API Key** 클릭)

⚠️ 무료 플랜 월 500크레딧이면 오늘 실습엔 충분하다.
⚠️ 발급이 막히면 강사가 배포한 **교육용 공용 키**를 받는다.

✅ 체크포인트: "`fc-`로 시작하는 키를 복사하셨나요?"

## G0-2. 네이버 데이터랩 키 발급 (회원가입부터)

이 단계에서 할 일: 네이버 개발자센터에 앱을 등록하고 ID/Secret을 받는다.

1. 브라우저에서 **https://developers.naver.com** 접속
2. 네이버 계정으로 **로그인** (없으면 네이버 회원가입)
3. 상단 **Application → 애플리케이션 등록** 클릭
4. 애플리케이션 이름은 아무거나 (예: 리서치실습)
5. **사용 API**에서 **데이터랩(검색어트렌드)** 과 **데이터랩(쇼핑인사이트)** 를 **둘 다 체크**
6. 환경 추가는 **WEB 설정**을 고르고, URL에 `http://localhost` 를 입력
7. 등록하면 **Client ID(긴 값)** 와 **Client Secret(짧은 값)** 이 나온다. 둘 다 복사

⚠️ **사용 API 2개 체크**를 빠뜨리면 데이터랩이 안 된다.
⚠️ **ID가 긴 값, Secret이 짧은 값.** 헷갈리지 않게 메모해 둔다.

✅ 체크포인트: "Client ID(긴 값)와 Secret(짧은 값)을 받으셨나요?"

## G0-3. 대화창으로 MCP 연결 (JSON 편집 없음)

이 단계에서 할 일: 발급받은 키를 **채팅창에 그대로 입력**해서 두 도구를 붙인다.

따라하기 (세 개의 { } 를 본인 키로 바꿔서 그대로 입력):
```
MCP 도구 두 개를 연결해줘. 내 키는 아래와 같아.
  · Firecrawl 키: {fc-로 시작하는 키}
  · 네이버 Client ID(긴 값): {긴 값}
  · 네이버 Client Secret(짧은 값): {짧은 값}
firecrawl은 firecrawl-mcp 패키지로, 네이버는 naver-datalab-mcp-server 패키지로 붙여줘.
설정 파일은 내가 직접 안 고쳐도 되게 네가 등록해줘
```

Claude 실행 규칙:
- 받은 키로 두 MCP(firecrawl · naver-datalab)를 등록한다. **수강생이 JSON을 직접 편집하지 않게 한다**
- 등록 후 "껐다 켜야 적용된다"고 안내한다
- 잘 안 되면 조교가 대신 붙여준다(또는 실습 파일 `.mcp.json`에 키만 넣어준다). 강의는 멈추지 않는다

✅ 체크포인트: "연결했다는 응답이 왔나요?"

## G0-4. 재시작 + 연결 확인

1. **안티그래비티를 껐다 켠다** (이걸 해야 도구가 뜬다)
2. 재시작 후 두 도구를 한 번에 확인한다:
```
두 가지만 확인해줘.
1) "AI 교육"으로 관련 기사 3건 제목을 보여줘        ← Firecrawl
2) 같은 키워드 최근 1년 검색 추이를 보여줘           ← 데이터랩
```

예상 결과: 기사 3건 제목 + 월별 검색 지수.

⚠️ **네이버 401 인증 실패**: ID와 Secret이 뒤바뀐 것이다. **ID가 긴 값, Secret이 짧은 값.**
⚠️ **데이터랩만 안 되면**: 앱 등록 때 데이터랩 2종 체크를 빠뜨린 것이다.
⚠️ **Firecrawl "Invalid token"**: 키를 다시 확인한다.

✅ 체크포인트: "둘 다 응답이 왔나요?"
- 성공 → G1로
- 실패 → **조교 개별 처리**. 강의는 G1로 진행한다. **한 사람 때문에 29명이 멈추면 안 된다**

목표: 오늘 조사할 주제 하나를 **내 직무에 맞게** 그 자리에서 고른다.

Claude 멘트 포인트: "거창하지 않아도 됩니다. 내 일과 가까운 것 하나면 됩니다. 옆 사람과 직무가 달라도 괜찮습니다. 각자 자기 주제로 같은 실습을 합니다."

Claude가 직무 팔레트를 출력한다 (내 직무에 가까운 걸 골라 변형):

```
직무별 주제 고르기 (내 직무에 가까운 걸 골라 변형)

  교육·러닝      내년에 수요가 늘 교육 주제 / 우리 과정 중 뜰 주제
  기획·전략      경쟁사의 올해 신규 움직임 / 지금 진입 vs 1년 뒤
  마케팅         우리 타겟이 요즘 반응하는 채널·메시지
  운영·CS        최근 불만·문의가 몰리는 지점
  IT·개발·데이터  검토 중인 기술이 도입기인가 성숙기인가
  HR·인사        우리 직무 채용 시장이 공급 과잉인가 부족인가
  공통           상사가 "요즘 이거 어때?"라고 물은 것 하나
```

```
내 직무는 "{직무}"이고, 조사하고 싶은 건 "{내 주제/키워드}"야.
이걸 조사하려면 어떤 걸 확인해야 하는지 3~4가지로 짚어줘.
그리고 데이터랩에 넣을 핵심 검색 키워드도 1~2개 뽑아줘
```

✅ 체크포인트: "직무에 맞는 주제 하나와 검색 키워드가 정해졌나요?"

# G2. Firecrawl 원문 조사 ★ (10분)

목표: Firecrawl로 "원문"을 조사한다. **많이 모으고, 대부분을 버린다.**

Claude 멘트 포인트 (실행 전에 먼저 말한다):
"지금부터 클로드가 자료를 **한 번에 십수 건** 긁어옵니다. 사람이 하면 반나절입니다.
그런데 그게 핵심이 아닙니다. **많이 가져온 다음에 대부분을 버리는 것**, 그게 딥리서치입니다."

따라하기:
```
"{내 주제}"로 관련 기사·페이지를 Firecrawl로 넓게 모아줘. 10건 이상.
그 다음 이 기준으로 걸러줘:
  · 출처 링크가 없으면 버린다
  · 3년 넘은 자료는 버린다
  · 같은 사실이 한 곳에만 있으면 "미확인"으로 표시한다
몇 건 가져와서 몇 건 남았는지 숫자로 말해줘.
남은 자료의 핵심 주장 3~4개를 정리해줘
```

Claude 실행 규칙:
- `firecrawl_search`로 관련 기사·페이지를 10건 이상 찾는다
- **몇 건 가져왔는지 숫자로 말한다** ("18건을 가져왔습니다")
- 중요한 자료는 `firecrawl_scrape`로 원문 본문을 가져온다
- 기준으로 거른 뒤 **몇 건 남았는지 숫자로 말한다** ("7건 남고 11건 버렸습니다")

Claude 멘트 포인트 (검증 직후):
"7건만 남았습니다. 11건을 버렸습니다.
**버린 11건이 이 리서치의 품질입니다.** 안 버리면 그냥 검색 요약이니까요."

✅ 체크포인트: "몇 건 가져와서 몇 건 남았나요? 원문의 핵심 주장이 정리됐나요?"

# G3. 데이터랩 수요 조사 ★ (10분)

목표: 같은 주제를 네이버 데이터랩으로 조사한다. **"얼마나 찾나"(실제 수요)** 를 본다.

따라하기:
```
G1에서 뽑은 검색 키워드로, 최근 1년 검색 추이를 데이터랩으로 조사해줘.
  · 키워드 1~2개의 월별 검색 지수
  · 올라가는 추세인지, 제자리인지, 내려가는지 한 줄로
  · 가장 높았던 달과 최근 달을 비교해줘
```

Claude 실행 규칙:
- `datalab_search`로 월별 검색 지수를 가져온다
- 추세(상승/정체/하락)를 한 줄로 요약한다
- ⚠️ 데이터랩은 트렌드만 준다. 뉴스·블로그·광고 성과는 범위 밖이다

✅ 체크포인트: "검색 추이가 나왔나요? 오르는지 제자리인지 말할 수 있나요?"

# G4. 결과 md + 2축 교차 ★ (10분)

목표: 원문(G2)과 수요(G3)를 합쳐 결과 md를 만들고, **둘이 엇갈리는 지점**을 찾는다. 여기서 인사이트가 태어난다.

따라하기:
```
G2(원문)와 G3(수요)를 합쳐서 `3교시 실습 결과/조사결과.md`로 정리해줘.
그리고 두 가지가 엇갈리는 지점을 찾아줘:
  · 기사·원문은 뭐라고 하는가 (Firecrawl)
  · 데이터랩 검색량은 실제로 어떤가 (수요)
구조:
  ## 확인된 사실   ## 미확인 사실   ## 원문·수요 교차(엇갈림)   ## 버린 정보(왜)
```

**자주 나오는 엇갈림 3종** (강사가 예시로 들 것):

| 패턴 | 뭘 뜻하나 |
|---|---|
| 기사·원문은 "뜬다"는데 검색량은 제자리 | 업계가 밀고 있을 뿐 소비자는 아직 모른다 |
| 검색량은 치솟는데 원문 근거는 얕고 오래됨 | 유행어일 뿐 실체가 얕다. 거품을 의심한다 |
| 관심은 느는데 구매·전환 신호는 약함 | 관심은 있는데 안 산다. 가격이나 장벽 문제 |

강사 멘트:
"요약은 기사를 그대로 옮깁니다. 딥리서치는 그 기사가 실제 수요와 맞는지 숫자로 되묻습니다.
**원문과 수요가 엇갈리는 그 지점, 거기서 인사이트가 나옵니다.**"

✅ 체크포인트: "조사결과.md가 생겼나요? 엇갈리는 지점을 하나라도 찾았나요?"

# G5. 시각화 (5분)

목표: 원문과 수요를 **한 장의 그림**으로 겹쳐 본다. 1교시의 "미검증" 그림과 달리, 이건 진짜 자료다.

따라하기:
```
조사결과.md를 한 장으로 시각화해줘.
  · 검색 수요(데이터랩)는 월별 추이 선 또는 막대로
  · 원문의 핵심 주장은 옆에 짧게
  · 엇갈리는 지점은 눈에 띄게 표시
외부 라이브러리 없이 단일 HTML로 만들고, 맨 위에
"실제 자료 · Firecrawl + 데이터랩" 배지를 넣어줘.
`3교시 실습 결과/조사_시각화.html`로 저장하고 브라우저로 열어줘
```

Claude 멘트 포인트: "1교시엔 '미검증' 배지가 붙었죠. 이번엔 '실제 자료'입니다. 같은 그림인데 근거가 다릅니다. 손을 붙이면 이렇게 달라집니다."

✅ 체크포인트: "브라우저에 그림이 떴나요? 맨 위 배지가 '실제 자료'인가요?"

# G6. 환각 시연 (선택 · 시간 남으면)

목표: **AI가 없는 자료를 지어내는 장면을 직접 본다.** 그래서 "출처 없으면 버린다"는 규칙이 필요하다.

따라하기 (**의도적으로 틀린 전제를 넣는다**):
```
{내 분야}에서 작년에 발표된 "{존재하지 않는 보고서 이름}"의 핵심 결론을 요약해줘
```

예시:
- "2025년 한국교육공학회의 '기업교육 AI 도입 효과 백서' 핵심 결론 요약해줘"
- "지난달 나온 산업연구원 '중소기업 AI 도입 실태조사 2026' 요약해줘"

| 결과 | 의미 | 강사 멘트 |
|---|---|---|
| 그럴듯하게 요약해준다 | **환각.** 없는 걸 지어냈다 | "지금 이거, 완전히 지어낸 겁니다. 근데 그럴듯하죠. 이걸 보고서에 넣으면?" |
| "찾을 수 없다"고 답한다 | 정직하게 답했다 | "이렇게 답해야 정상입니다. 근데 규칙이 없으면 지어냅니다" |

Claude 실행 규칙: 만약 지어냈다면 **솔직하게 인정하고** "출처를 확인할 수 없어 지어낸 것"이라고 밝힌다.

Claude 멘트 포인트:
"AI는 모른다고 말하는 것보다 그럴듯하게 답하는 걸 더 잘합니다.
그래서 '출처 없으면 버린다'는 규칙이 필요합니다. 4교시엔 이 규칙을 아예 파일에 담아둔 에이전트를 만듭니다."

✅ 체크포인트: "지어내던가요, 아니면 못 찾겠다고 하던가요? 어느 쪽이든 이유를 이해하셨나요?"

## 트러블슈팅

| 증상 | 원인 | 해결 |
|---|---|---|
| MCP 등록 후 도구가 안 보임 | IDE 재시작 안 함 | 안티그래비티 완전 종료 후 재실행 |
| 네이버 401 인증 실패 | ID/Secret 뒤바뀜 | **ID가 긴 값, Secret이 짧은 값.** 두 값을 바꿔 넣는다 |
| 데이터랩이 광고 성과를 못 준다 | 데이터랩의 범위 | 정상이다. ROAS는 SearchAd 영역. 오늘 범위 밖 |
| Firecrawl "Invalid token" | 키가 .mcp.json에 안 들어감 | `FIRECRAWL_API_KEY` 값 확인 |
| Firecrawl 크레딧 소진 | 무료 500/월 초과 | 검색·크롤 대상 수를 줄인다. 강사 공용 키 투입 |
| 검색 결과가 너무 많다 | 키워드가 넓다 | 기간·지역을 더 자른다 |
| 검색 결과가 거의 없다 | 키워드가 너무 좁거나 세부적 | 한 단계 위 개념으로 넓힌다 |
| 직무 주제가 안 떠오른다 | 주제 미준비 | 직무 팔레트에서 골라 본인 상황으로 변형 |
