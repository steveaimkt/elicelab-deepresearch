# 내 리서치 (교육용 폴더)

엘리스랩 · AI로 완성하는 딥리서치 리포트 입문 (2026년 7월 24일)

이 폴더는 **밥상이 차려진 상태**입니다. 어려운 설정은 이미 다 돼 있습니다.
여러분이 할 일은 **키 세 줄 붙여넣기**와 **한국어로 대화하기**, 이 둘뿐입니다.

---

## 오늘 할 일 (딱 3단계)

### 1단계. 이 폴더를 안티그래비티로 연다

안티그래비티를 실행하고, 이 폴더를 엽니다. 왼쪽에 파일 목록이 보이면 성공입니다.

### 2단계. 내 키를 붙여넣는다 (3교시 MCP 연결에서)

왼쪽 파일 목록에서 **`.mcp.json`** 을 클릭해서 엽니다.
`여기에_붙여넣기` 라고 적힌 자리가 **세 군데** 있습니다. 그 자리에 본인 키를 넣고 저장합니다.

| 자리 | 넣을 것 | 어디서 받나 |
|---|---|---|
| `FIRECRAWL_API_KEY` | Firecrawl 키 | firecrawl.dev → API Keys |
| `NAVER_CLIENT_ID` | 네이버 **긴** 값 | developers.naver.com → 내 애플리케이션 |
| `NAVER_CLIENT_SECRET` | 네이버 **짧은** 값 | 같은 화면 |

⚠️ **네이버 앱 등록할 때 "사용 API"에서 두 개를 체크했는지 확인하세요.**
`① 데이터랩(검색어트렌드)` `② 데이터랩(쇼핑인사이트)`
하나라도 빠지면 그 기능만 안 됩니다. 키는 두 개가 아니라 하나(ID/Secret 쌍)입니다.

⚠️ **다른 부분은 건드리지 마세요.** 따옴표와 쉼표는 그대로 두고, 글자만 바꿉니다.
⚠️ 저장한 뒤 **안티그래비티를 껐다 켜야** 적용됩니다.

### 3단계. 대화한다

클로드 코드 패널에서 한국어로 말을 겁니다. 그게 전부입니다.

```
기초 실습 시작
```

---

## 오늘의 흐름

| 교시 | 이 말을 입력하세요 | 만들 것 |
|---|---|---|
| 1교시 | `기초 실습 시작` | 도구 세팅 + 리서치 질문 연습 |
| 2교시 | `스킬 제작하자` | 리포트 보고서 스킬 (샘플 자료로) |
| 3교시 | `MCP 연결하자` | 웹 조사 손 붙이기 + 근거 목록 |
| 4교시 | `에이전트 구축하자` | 조사하는 에이전트 + 메일 발송 |

**각 교시는 따로 진행됩니다.** 하나 놓쳐도 다음 교시에 그대로 들어올 수 있습니다.

---

## 자주 막히는 지점

| 이럴 때 | 이렇게 하세요 |
|---|---|
| 키를 넣었는데 안 된다 | 안티그래비티를 완전히 껐다 켰나요? 저장(Cmd+S / Ctrl+S)은 했나요? |
| 네이버가 401 오류 | ID와 Secret이 바뀌었습니다. **긴 게 ID, 짧은 게 Secret** |
| 파일이 빨간 줄로 표시된다 | 따옴표나 쉼표를 지웠을 가능성이 큽니다. 조교를 부르세요 |
| 클로드가 응답을 안 한다 | 로그인이 풀렸을 수 있습니다. `안녕, 로그인 돼 있어?` 라고 물어보세요 |
| 어느 패널이 클로드인지 모르겠다 | 안티그래비티에는 구글 에이전트도 있습니다. **클로드 코드 패널만** 씁니다 |

혼자 해결하려 하지 마세요. **손을 들면 조교가 갑니다.**

## 폴더 안에 뭐가 있나

```
내-리서치/
├── README.md      이 문서
├── .mcp.json      MCP 설정 (키만 넣으면 됨. 나머지는 완성돼 있음)
└── CLAUDE.md      에이전트 업무 지침서 (1교시에 함께 채웁니다)
```

교육이 끝나면 이 폴더가 이렇게 자라 있을 겁니다.

```
내-리서치/
├── 00_리서치질문.md            1교시
├── 리포트-스킬/SKILL.md         2교시  ← 보고서 만드는 스킬
├── 근거자료목록.md             3교시  ← 웹에서 모은 근거
├── 딥리서치-에이전트/SKILL.md   4교시  ← 조사하는 에이전트
└── 조사결과.md                 4교시  ← 오늘의 결과물 (승인 후 Gmail로 발송)
```

## 교육이 끝난 뒤

이 폴더를 **지우지 마세요.** 다음 달에 같은 조사를 다시 할 때, 두 마디면 됩니다.

```
내 리서치 돌려줘. 이번엔 {다른 주제}로
보고서 뽑아줘
```

오늘 4시간이 다음엔 20분이 됩니다.

⚠️ **교육용 공용 키를 받으신 분**은 교육 후 본인 키로 교체하세요. 공용 키는 교육 종료와 함께 폐기됩니다.
