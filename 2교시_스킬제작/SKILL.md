# 2교시 분야별 리서치 스킬 만들기 (게이트형·독립)

> 이 스킬은 게이트형이다. 한 번에 다 실행하지 말 것.
> 게이트 하나 = 응답 하나 + 질문 하나. 수강생 답을 받고 다음 게이트로 넘어간다.
> 목표: **스킬이 무엇인지** 손으로 익히고, 1교시보다 **리서치도 보고서도 한 단계 깊게** 만든다. 분야별 리서치 스킬로 체계적으로 조사하고(확인 항목·인사이트·반대 근거), 내용에 맞는 리포트 한 장으로 낸다.
> 웹서치는 클로드 기본 검색을 쓴다. 전문 수집 도구(대량·2축)는 3교시.

## 진행 원칙 (Claude가 지킬 것)

1. 한 게이트씩: 현재 게이트만 안내하고 수강생의 완료 응답을 기다린다
2. **G1을 서두르지 않는다**: 스킬 만들기가 이 교육의 핵심이다. SKILL.md가 눈에 보여야 한다
3. **분야에 맞게**: G0에서 리서치 분야를 하나 고르게 하고, 그 분야에 맞춘 스킬을 만든다
4. **보고서(pptx)를 만들지 않는다**: 시각화는 리포트형 HTML 한 장까지. pptx는 4교시
5. 복붙 우선: 수강생이 입력할 프롬프트는 코드 블록으로
6. 진행 현황 표시: 매 게이트 시작 시 `[G번호 · 제목]`
7. **웹서치는 기본 검색만**: 전문 수집(대량·2축)은 3교시. "그건 3교시에 붙입니다"

## 시작 멘트

```
2교시를 시작합니다. 오늘 처음으로 "내 스킬"을 만듭니다.

  스킬이 뭘까요?
  한 줄로: 내 판단 규칙을 저장해두는 파일입니다.

  매번 "출처 붙여줘, 결론부터 써줘, 반대 근거도 넣어줘"라고 말하는 대신,
  그 규칙을 파일 한 장에 적어두면 클로드가 대신 기억합니다.
  그 파일이 바로 스킬(SKILL.md)입니다.

오늘 만들 것: 내 분야에 맞는 리서치 스킬
  분야를 하나 고르고 → 그 분야에 맞춘 리서치 스킬을 만들고 →
  웹서치로 조사해서 → 내용에 맞는 리포트 한 장으로 냅니다.

  1교시보다 한 단계 위입니다.
  리서치는 스킬로 체계화되고(확인 항목·인사이트·반대 근거),
  보고서는 그림 나열이 아니라 제대로 된 리포트 한 장이 됩니다.
  웹서치는 기본 검색을 씁니다. 전문 수집 도구는 3교시에.

4단계로 갑니다 (약 55분):

  G0  스킬이란 + 분야 선택       (10분)
  G1  분야별 리서치 스킬 만들기 ★  (20분)  ← 오늘의 핵심
  G2  스킬 실행 · 웹서치 조사      (15분)  ← 조사결과 md
  G3  리포트형 시각화            (10분)  ← 내용에 맞는 리포트 한 장

준비되셨으면 "시작"이라고 입력해 주세요.
```

목표: 스킬 개념을 잡고, 오늘 만들 리서치 스킬의 **분야**를 하나 고른다.

```
"2교시 실습 결과" 폴더를 만들어줘. 2교시 실습은 여기서 할 거야
```

✅ 체크포인트: "왼쪽 탐색기에 `2교시 실습 결과` 폴더가 보이나요?"

## G0-2. 리서치 분야 고르기

Claude 멘트 포인트: "리서치도 종류가 있습니다. 시장을 보는지, 경쟁사를 보는지, 고객을 보는지에 따라 확인할 것이 다릅니다. 내 일에 가까운 분야를 하나 고르면, 그 분야에 맞춘 스킬을 만듭니다."

```
  A  시장·트렌드 조사 스킬   "이 시장·주제가 뜨는가, 지는가"        → 교육·기획·전략
  B  경쟁사 조사 스킬        "경쟁사가 올해 뭘 새로 했나"           → 기획·마케팅
  C  고객·타겟 조사 스킬      "우리 타겟이 뭘 원하고 왜 안 사나"      → 마케팅·운영·CS
  D  기술·도구 조사 스킬      "이 기술이 도입기인가 성숙기인가"        → IT·개발·데이터

어떤 분야로 갈까요? (A / B / C / D)  못 고르면 직무를 알려주세요. 추천해 드립니다.
```

Claude 실행 규칙: 고른 분야에 따라 G1에서 스킬의 "확인 항목"이 달라진다. (시장=수요·성장·진입장벽 / 경쟁사=신규출시·강약점 / 고객=니즈·이탈원인 / 기술=성숙도·도입사례)

✅ 체크포인트: "리서치 분야 하나를 고르셨나요?"

# G1. 분야별 리서치 스킬 만들기 ★ (20분)

> **이 게이트가 오늘의 핵심이다. SKILL.md가 눈에 보여야 한다.**

목표: 고른 분야에 맞춘 조사·판단 규칙을 파일 한 장으로 만든다. **이 파일이 여러분의 리서치 스킬이다.**

Claude가 먼저 출력한다:

```
리서치 스킬은 "이 분야를 조사하는 나의 방식"을 파일에 적어두는 겁니다.

  ① 무엇을 확인할지    분야에 맞는 확인 항목 (시장이면 수요·성장·장벽)
  ② 어떻게 조사할지    웹서치로 찾고, 출처를 붙인다
  ③ 어떻게 판단할지    인사이트는 비교·반전·결정영향 중 하나. 반대 근거도 넣는다
```

Claude 멘트 포인트: "지금 만드는 SKILL.md 한 장이 스킬 본체입니다. 왼쪽 탐색기에서 눈으로 보세요. 이게 안 보이면 '클로드가 뭘 해줬다'로 끝나고, 보이면 '내가 스킬을 만들었다'가 됩니다."

따라하기 (**{분야}에 A~D에서 고른 것을 넣는다**):
```
{분야} 리서치 스킬을 만들어줘.
`2교시 실습 결과/리서치-스킬/SKILL.md`로 저장해줘.

입력: 조사 주제 한 줄

확인 항목 (이 분야에 맞게):
  · {분야에 맞는 확인 항목 3~5개를 네가 제안해줘}

조사 방법:
  · 기본 웹서치로 관련 자료를 찾는다 (전문 수집 도구는 3교시)
  · 모든 사실에 출처 링크를 붙인다. 못 붙이면 뺀다

판단 규칙:
  · 인사이트는 비교 / 반전 / 결정영향 중 하나여야 한다. 없으면 없다고 말한다
  · 반대 근거가 있으면 반드시 넣는다. 없으면 "반대 근거 못 찾음"이라고 쓴다
  · 출처가 1곳뿐인 사실은 "미확인"으로 표시한다

출력: `2교시 실습 결과/조사결과.md`
  # {제목}
  질문 / 결론
  ## 확인 항목   - {항목}: {조사 내용} :: {확인 or 미확인}
  ## 인사이트    - [반전/비교/결정영향] {한 줄} :: {근거·출처}
  ## 반대 근거
  ## 출처
```

Claude 실행 규칙:
- SKILL.md를 실제 파일로 만들고 **열어서 보여준다**
- frontmatter에 name, description, 트리거를 넣는다 (트리거는 수강생이 정한다)
- **고른 분야에 맞는 확인 항목**을 구체적으로 제안한다
- 출력은 조사결과 md다. 보고서(pptx)는 만들지 않는다

Claude 멘트 포인트 (파일 보여준 뒤):
"규칙이 파일에 글로 적혀 있죠. 매번 말할 필요가 없습니다. 이 파일이 대신 기억합니다.
다음 달에 주제만 바꿔 다시 부르면, 같은 분야 기준으로 같은 품질이 나옵니다."

✅ 체크포인트: "왼쪽 탐색기에 SKILL.md가 보이나요? 내 분야에 맞는 확인 항목이 들어갔나요?"

# G2. 스킬 실행 · 웹서치 조사 (15분)

목표: 방금 만든 리서치 스킬을 내 주제로 돌려, **웹서치로 구체화된 조사 결과(md)** 를 만든다.

따라하기:
```
방금 만든 리서치 스킬을 내 주제 "{내 주제}"로 실행해줘.
확인 항목을 하나씩 웹서치로 조사하고, 출처를 붙이고, 인사이트까지 뽑아서
`2교시 실습 결과/조사결과.md`로 저장해줘.
출처 1곳뿐이면 "미확인"으로 표시해줘
```

Claude 실행 규칙:
- SKILL.md 규칙대로 확인 항목을 **기본 웹서치**로 조사 → 인사이트 → md 저장
- 모든 사실에 출처 링크. 없으면 뺀다
- 인사이트는 비교·반전·결정영향 중 하나. 억지로 개수를 채우지 않는다

Claude 멘트 포인트:
"1교시 손풀기보다 훨씬 체계적이죠? 스킬이 분야 기준으로 항목을 나눠 조사했으니까요.
같은 주제라도 스킬이 있으면 매번 같은 잣대로 조사합니다. 그게 스킬의 힘입니다."

✅ 체크포인트: "`조사결과.md`가 생겼나요? 확인 항목마다 출처가 붙었나요?"

# G3. 리포트형 시각화 (10분)

목표: 조사 결과를 **내용에 맞는 리포트 한 장**으로 시각화한다. 1교시가 "그림 5종"이라면, 2교시는 "잘 짜인 리포트 하나".

Claude 멘트 포인트: "1교시엔 같은 결과를 여러 그림으로 봤죠. 오늘은 반대입니다. 내용에 가장 맞는 리포트 형태 하나를 골라, 제대로 된 한 장으로 만듭니다."

## G3-1. 리포트 형태 제안

따라하기:
```
조사결과.md의 내용을 보고, 어떤 리포트 형태가 가장 맞는지 제안해줘.
(예: 시장분석 리포트 / 트렌드 브리핑 / 경쟁사 비교표 / 고객 인사이트 카드)
왜 그 형태가 맞는지도 한 줄로
```

Claude 실행 규칙: 조사 내용에 맞는 리포트 형태를 1~2개 추천하고, 이유를 붙인다. (수요·추세 중심이면 트렌드 브리핑, 여러 대상 비교면 비교표 등)

## G3-2. 리포트 한 장 만들기

따라하기:
```
방금 제안한 형태로 조사결과.md를 리포트 HTML 한 장으로 만들어줘.
구조: 제목 / 한 줄 결론 / 핵심 인사이트(근거·출처) / 반대 근거 / 근거 목록.
내용에 맞는 그래프나 표를 리포트 안에 자연스럽게 넣어줘.
외부 라이브러리 없이 단일 HTML로, 맨 위에 "웹서치 기반 리포트" 배지를 넣고
`2교시 실습 결과/리포트.html`로 저장하고 브라우저로 열어줘
```

Claude 실행 규칙:
- 외부 라이브러리 없이 단일 HTML. 리포트 레이아웃(제목·결론·인사이트·근거)
- 내용에 맞는 그래프·표를 리포트 안에 배치 (1교시처럼 여러 종류 나열이 아니라, 리포트에 녹인다)
- 모든 주장에 출처. `open`으로 브라우저를 연다

Claude 멘트 포인트: "1교시는 '어떤 그림이 맞나'를 골랐고, 2교시는 '내용에 맞는 리포트'를 만들었습니다. 이 리포트를 만드는 규칙이 스킬에 들어 있으니, 다음엔 주제만 바꾸면 됩니다."

✅ 체크포인트: "리포트 HTML이 브라우저에 떴나요? 결론·인사이트·근거·출처가 한 장에 담겼나요?"

## 트러블슈팅

| 증상 | 원인 | 해결 |
|---|---|---|
| 어떤 분야를 골라야 할지 모른다 | 분야 미정 | 직무를 알려주면 추천. 시장/경쟁사/고객/기술 중 하나 |
| 인사이트가 3개 안 나온다 | 자료 부족 (정상) | **억지로 채우지 않는다.** 2개면 2개 |
| 클로드가 사실처럼 단정한다 | 출처 없이 씀 | "출처 없으면 미확인으로 바꿔줘" |
| 기본 웹서치가 안 된다 | 환경 제약 | 아는 선으로 정리하고 "미확인" 표시. 제대로 된 수집은 3교시 |
| SKILL.md가 안 보인다 | 경로 착오 | "방금 만든 SKILL.md 경로 알려줘" |
| 리포트가 밋밋하다 | 형태가 안 맞음 | "내용에 더 맞는 리포트 형태로 다시 제안해줘" |
| 보고서(pptx)를 만들려 한다 | 4교시와 혼동 | 2교시는 리포트 HTML까지. pptx는 4교시 |
