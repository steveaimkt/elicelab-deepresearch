# 엘리스랩 딥리서치 교육 · 실습 스킬 4종

2026년 7월 24일(금) 4시간 교육용. 안티그래비티 IDE + 클로드 코드 기준.

## 구성

```
실습파일/
├── 0_교육용폴더/                  수강생 배포용 실습 파일 (.mcp.json 백업 포함)
├── 1교시_기초실습/SKILL.md        질문 → 웹서치 → 정리 → 다양한 시각화 5종
├── 2교시_스킬제작/SKILL.md        분야별 리서치 스킬 → 웹서치 조사 → 리포트형 시각화
├── 3교시_MCP연결/SKILL.md         MCP 2종 발급·연결(대화창) → 각 1건 조사 → 2축 → 시각화
└── 4교시_에이전트구축/SKILL.md     질문→스킬→MCP→pptx→발송 한 번에 완성
```

**각 교시는 독립이다.** 앞 교시 산출물을 요구하지 않는다. 늦게 온 사람도, 하나 빠진 사람도 아무 교시나 들어올 수 있다.
필요한 입력(분야·주제·키워드)은 각 스킬이 그 자리에서 스스로 마련한다.

**교시마다 결과 폴더를 분리한다.** 1교시는 `1교시 실습 결과`, 2교시는 `2교시 실습 결과` … 각자 자기 폴더에서 진행한다.

**모든 실습은 직무·분야에 맞게 고른다.** 혼합 직무(교육·기획·마케팅·운영·IT·HR)가 각자 자기 주제로 같은 실습을 돌린다.

## 도구 사다리 (점점 강해진다)

```
1교시  기초        기본 웹서치로 질문→검색→정리→다양한 시각화 5종
2교시  스킬        분야별 리서치 스킬을 만들어 웹서치 조사 → 리포트 한 장
3교시  MCP         전문 도구(Firecrawl·데이터랩)를 발급·연결 → 대량수집·수요 2축
4교시  에이전트     규칙을 파일에 담아 질문부터 발송까지 자동으로
```

- **1·2교시 = 기본 웹서치**, **3교시 = 전문 MCP(2축)**. 2교시의 가치는 "웹 처음"이 아니라 **스킬로 규칙화·재현**.
- **시각화 차이**: 1교시 = 같은 결과의 다양한 그림 5종 / 2교시 = 내용에 맞는 리포트 한 장 / 3교시 = 원문·수요 2축 / 4교시 = pptx 보고서.

## 사용법

교육 당일, 네 폴더를 수강생 작업 폴더(또는 `~/.claude/skills`)에 넣으면 트리거로 호출된다.

## 설계 원칙

- **게이트형이다.** 한 응답 = 한 단계 + 질문 하나. 묶어서 빨리 넘기지 않는다
- **독립이다.** 각 교시는 자기 입력을 스스로 마련한다. 앞 교시를 놓쳐도 진행된다. 결과 폴더도 교시별로 분리
- **직무·분야로 고른다.** 모든 실습은 수강생 직무·분야에 맞게 주제를 선택해 진행한다
- **파일이 눈에 보여야 한다.** SKILL.md가 왼쪽 탐색기에 뜨는 것이 이 교육의 핵심 장면이다. 안티그래비티를 고른 이유
- **3교시는 완전 초보 기준.** 회원가입·API 발급부터 스텝별로 안내하고, JSON을 직접 고치지 않고 대화창으로 연결한다
- **환각 시연은 남긴다.** 없는 자료가 튀어나오는 장면 하나가 강의 전체보다 오래 남는다 (3교시 선택 스텝)
- **외부 전송은 승인 게이트.** 4교시에서 Gmail로 보내기 전에 반드시 묻는다

## MCP 2종 + Gmail 커넥터

| 도구 | 담는 것 | 방식 |
|:--|:--|:--|
| `firecrawl` | 기사·원문 검색·수집 (`firecrawl-mcp`) | firecrawl.dev 가입 → API 키 (무료 500크레딧/월) |
| `naver-datalab` | 검색어 트렌드 (`naver-datalab-mcp-server`) | developers.naver.com 앱 등록 → ID/Secret |
| Gmail | 결과물 발송 (4교시) | 키 없음. 커넥터 OAuth 연결만 |

3교시는 위 키를 **수강생이 직접 발급**받아 **대화창에 입력**해 연결한다(JSON 편집 없음). `.mcp.json`은 백업 경로다.

**원문 · 수요 2축 구조**

| 도구 | 답하는 질문 |
|:--|:--|
| Firecrawl | **원문**은 뭐라고 하나 (관련 기사·페이지를 넓게 찾고 본문 통째로) |
| 네이버 데이터랩 | **얼마나** 찾나 (검색 트렌드) |

둘이 엇갈리는 지점에서 인사이트가 나온다. 3교시 G4가 그 장면이다.
(기사·원문은 "뜬다"는데 데이터랩 검색량은 제자리면, 업계만 밀 뿐 소비자는 아직 모른다.)

⚠️ 네이버 앱 등록 시 사용 API **두 개 체크** : 데이터랩(검색어트렌드) + 데이터랩(쇼핑인사이트)
⚠️ 네이버 데이터랩은 트렌드만 준다. 광고 성과(ROAS)는 범위 밖이다.
⚠️ 401 인증 실패는 ID/Secret이 뒤바뀐 경우가 대부분이다. **ID가 길고 Secret이 짧다.**
